## 📖 About The Project

**Zoya AI** is a modern, full-stack AI-powered web application designed to deliver a smooth, intelligent, and engaging user experience. Built with a robust **TypeScript** foundation across both the frontend and backend, Zoya combines clean architecture with a polished, production-ready interface.

> 💡 This is a **personal / commercial product** built and maintained by **Abhishek Yadav**. It is **not open source** — the codebase is proprietary and intended for personal/business use only.
